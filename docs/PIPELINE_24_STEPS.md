# The 24-step pipeline (transcribed from the reference video)

Stack: **Claude Code** = director + editor (file access, Python, ffmpeg, faster-whisper, librosa).
**ImagineArt MCP** = every AI image and video: Nano Banana Pro stills (4K, 16:9) and Seedance 2.5
reference-to-video clips. **Blender 5** = previz. Premiere optional.

Target: ~60 s game-trailer-style AI short, 16:9, 24 fps, about 45 clips of 10 s.

Each step below lists what the video says and **where it lives in this repo**.

| # | Step | Rule summary | Implemented by |
|---|------|--------------|----------------|
| 01 | The brief | Standing rules set before any work: Claude ends video tasks at upload folders + prompts + HTML copy page; the human runs generations; never auto-generate video; never crop/resize a reference; reprint the full prompt on every change; ask before rendering. | skill `ai-film-pipeline`, `/film-new` |
| 02 | Study the references | Tile reference trailers (`ffmpeg fps=1,tile`). Measure shot-length distribution, cut rhythm vs music, dialogue density per 10 s, day/night + colour mix, recurring locations, who shares scenes. Output a pacing-and-style doc and a scene-design doc. Derive your own scene list; never recreate shots. Reference stills never go into generation inputs. | agent `researcher`, `fp refs` |
| 03 | Design the scenes | One row per scene: ID, cast (max two speaking), location plate, a single action, two short lines or none, camera idea, 10 s, 16:9. Mix dialogue two-shots, silent emote shots, gameplay-camera fillers. Every scene has an outfit/accessory change. Neighbouring scenes never reuse the same character pair. Show the set as one picture + numbered table, get sign-off. Stable IDs (N01, V11, B5) key folders, prompts, edit decisions. | agent `scene-designer`, `fp scenes check/table/board` |
| 04 | Lock the look | Every image and video prompt starts with one system prompt, verbatim, never paraphrased, plus one shot-specific line tying grade to the plate. | `pipeline/look.py` (`LOOK`), `fp look` |
| 05 | Character sheets | Nano Banana Pro 4K 16:9. Two sheets per character per outfit: Sheet1 full-body turnaround (front, 3/4, profile, back, head to soles, same scale); Sheet2 six-tile headshots (3x2: neutral front, 3/4, profile, smirk, shout, grin). Seamless dark grey backdrop, neutral pose, outfit garment by garment. Build Sheet2 from a single 4:5 portrait (not the turnaround). Outfit variant = edit from both sheets, change only clothing; new headwear needs a matching face sheet. Never merge/crop/cap/drop sheets. | agent `art-department`, `fp sheet-prompts` |
| 06 | Location plates | One empty-set plate per location per time of day: 4K, 16:9, stated camera height, no people/text/logos. Plates set brightness + palette (night scene → night plate). Dark clip → regenerate plate, never colour-boost. A plate whose framing matches the shot makes Seedance cut mid-shot: frame plates from a different angle or drop them. Vehicles get a four-view sheet. | agent `art-department`, `fp plate-prompts` |
| 07 | Brief Blender the right way | One markdown brief per clip, written for an agent: WHAT THIS IS FOR; WHAT WE LEARNED (numbered failures); FILES (abs paths); WHAT TO RENDER (frames, fps, 1920x1080, one mp4); LOOK (plain grey Workbench, distinct greys for sky/water/road/people); THE SET in metres with XYZ; CHARACTERS (height, build, hair shape, start pos); CAMERA as a timed flight path (pos, look-at, 24-35 mm, max bank 25°, 5 m clearance); TIMELINE by second; FINAL CHECKS. "No mood board, render straight away." One continuous camera, never a cut. | agent `previz-director`, `fp previz-brief`, `blender/previz.py` |
| 08 | Blender previz | Seedance copies previz camera/framing/blocking/poses/timing almost frame for frame; wording doesn't override it. Wrong action = change the render. Mannequins: neutral faces, no jaw anim, already in acting pose, different build/hair/pose each, no props, never closer than 2.5 m, never cut by frame edge. People near lens multiply. Line roads with repeating objects. Never fly through foliage. Reserve empty sky for titles + small fixed tracking dots. | `blender/previz.py` (checks enforced) |
| 09 | Prompt without a previz | Fixed section order: FORMAT, REFERENCE ROLES, THE LOCATION AND WHO IS WHERE, THE PEOPLE, FRAMING, EYE LINE, MOUTH, TIMELINE (second by second), CAMERA, PACE, PERFORMANCE, CONTINUITY, AUDIO, LOOK, CONSTRAINTS. Keep the three no-cuts lines. Bind every reference by number. One name per character. State screen side. Each action happens once. End on a described last frame. No en/em dashes. Ship as numbered upload folder + HTML copy page. | agent `prompt-writer`, `fp prompt`, `fp upload` |
| 10 | Prompt with a previz | Watch the render first (frame grid at 0.5 s), write what it shows. @Video1 owns camera/framing/positions/poses/timing; sheets own identity + props; plates own light; prompt covers only what none show. Grey figures are layout only, everyone fully dressed in listed outfit. Map each mannequin to a named person in screen order, each appears exactly once. Never fix pose/count/prop with wording. | agent `prompt-writer`, `fp grid`, `fp prompt --previz` |
| 11 | Generate the shot | Human runs Seedance 2.5 ref-to-video on ImagineArt. Upload in prompt order: Video1 previz, Image01+ plates, then face sheet + full sheet per person. 10 s 16:9. Rich scene sound, no music; ban risers/whooshes/hits/human non-speech. "Sensitive content" = picture, "output audio" = sound: fix only that side. 2-4 takes; reject by suffixing filename with `x`. | human + `fp takes` |
| 12 | When it breaks, fix the cause | Lookup table of symptom → cause → fix. | agent `continuity-critic` (`docs/FIX_TABLE.md`) |
| 13 | Pick the takes | faster-whisper word timestamps for every clip → one table (clip, line, speaker pair, usable in/out, silent ranges). Newest/primary folders weighted first, older 15-25% lower. One banger line per clip beats a full exchange. A clip can be used twice. Snap dialogue in/out to nearest silence. Log unused clips + why. | agent `dailies`, `fp transcribe`, `fp dailies` |
| 14 | Build the cut on the music | librosa beat-track + lyrics transcript. Offset song so first lyric lands on title card; hard-stop on chosen end word (fixes length). Song form: cold open, title, set-up verse, chorus of one-liners, beat-locked montage on the drop (0.25-0.5 s hits, action opens it), quiet verse for emotional pair, outro. Intercut by splitting. J/L cuts only where motivated. | agent `editor`, `fp beats`, `fp board-init` |
| 15 | Ask before rendering | Numbered order board (thumb, timecode, source, line) + multiple-choice questions with one recommended option. Render only after sign-off. Machine-verify after each render: transcribe mix vs planned lines, frame sheet, LUFS + true peak. Report what was measured and what was not heard/watched. | agent `editor`, `fp orderboard`, `fp verify` |
| 16 | Build your own editor | Local web page: Python server with range requests, 640x360 proxies, clip bins w/ hover scrub, two monitors, free-position timeline (nothing ripples), picture + sound trimmed independently, V/A layers, snapping, waveforms, per-layer mute, notes + colour tags, 20-step undo. Save writes JSON; Send to Claude writes a request file. A communicator, not an NLE. | `editor/` (`fp editor`) |
| 17 | Edit on the board, send it back | Item = clip, t, inp/out, ain/aout, vt/at, mute, nov, noa, note. On "sent", diff JSON vs last cut, report added/removed/retimed; fill gaps ≤3 frames; render exactly what's there (topmost video wins, real gaps black, pink-tagged keep dialogue). Sent board = new baseline. | `fp board-diff`, `fp render-cut` |
| 18 | Colour grade | ffmpeg chain in gbrp16le: lut3d tetrahedral at 57.7%; halation (curves knee 0.72, gblur σ29, warm mix, screen 35%); eq contrast 0.98 sat 1.07; bloom σ14 screen 17% on body shots; titles; grain last (1440x810 noise upscaled, grainmerge, luma 13.8). x264 slow CRF 14 ≤50 Mbps. | agent `finishing`, `pipeline/grade.py` |
| 19 | Custom title font | Font generated in code (skeleton → SDF stroke → marching squares → Bezier → CFF .otf). Blender render per word (bevel, voxel remesh, metallic Principled BSDF, Cycles 2400x1200, transparent film). One Blender at a time. | `blender/title.py` (any font; custom font generator is optional, see README) |
| 20 | Tracked titles | ProRes 4444 alpha overlays tracked to one source clip: overlay frame 0 = clip frame 0; head trim N → overlay trim N. Never retime/reframe the clip. Composite after grade, before grain. | `pipeline/titles.py` |
| 21 | Subtitles | Helvetica Neue Medium 49 px @1080p, sentence case, white, no shadow, centred, line centre at 88% height, one line ≤42 chars. Time from voice energy onset to end of last word, cross-checked with word times; on one frame early, hold 0.25 s, never into next line. Alpha track + SRT + burned preview. Flag bright backgrounds. | `pipeline/subtitles.py` |
| 22 | Three-layer sound | Stems: dialogue, clip scene sound, music. Clip sound 4-frame constant-power crossfades, tails ≤0.5 s, full in montage, ~12 dB under speech elsewhere. Music: dip only 350-4500 Hz by ~4.6 dB across whole dialogue segments (0.8 s down, 1.2 s up), full in montage. Dialogue +2 dB in montage. Master -14 LUFS, TP ≤ -1 dBTP. | agent `sound`, `pipeline/mix.py` |
| 23 | Effects and the echo fix | Designed FX last (risers, whoosh into title, hit on drop, riser-hit-whoosh into end card), 3 dB under spec, 12% dark room reverb, cut tails over lines. Echo → cross-correlate dialogue stem vs clip audio; constant lag = double voice; shift and blend. Optional clarity: -2 dB @280 Hz, +2.5 dB @3.6 kHz, shelf 9 kHz, de-esser. | `fp echo`, `pipeline/mix.py` |
| 24 | The upload | Master in one pass from cut intermediate: grade, titles, grain, subtitles, final mix. H.264 High 1920x1080 24 fps CRF 14 ≤50 Mbps, bt709, faststart, AAC 320k. Verify: frame count, loudness, TP, transcript vs cut, intro/body/outro frames. Keep stems, SRT, alpha, board JSON, scripts beside it. | agent `mastering`, `fp master`, `fp verify` |
